## 🎯 **WAT IS PIPELINE 1?**

## 🔄 **DATA FLOW**

### **Upload Flow:**
```
1. User uploads track via S3
   ↓
2. S3 trigger → upload-processor Lambda
   ↓
3. Extract metadata → metadata-extractor
   ↓
4. Store in DynamoDB
   ↓
5. Publish to IoT (new track available)
   ↓
6. Update playlists
```

### **Streaming Flow (without EC2):**
```
1. playlist-generator creates queue
   ↓
2. stream-track-pusher → SQS queue
   ↓
3. SQS messages available
   ↓
4. EC2 (Pipeline 2) will consume queue
   (In Pipeline 1, queue just fills up)
```

### **Real-time Updates:**
```
1. DynamoDB Stream
   ↓
2. stream-status-publisher Lambda
   ↓
3. IoT Core publish
   ↓
4. WebSocket clients (listeners)
```
