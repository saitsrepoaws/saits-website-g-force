## 🛠️ **TECHNISCHE INTEGRATIE**

### **Voor Developers:**

```typescript
// Lambda: news-voice-generator
import { Polly } from '@aws-sdk/client-polly';
import { S3 } from '@aws-sdk/client-s3';

// 1. Fetch nieuws
const news = await fetchNewsArticles();

// 2. Generate script
const script = generateNewsScript(news, '2-minutes');

// 3. Text-to-Speech
const audio = await polly.synthesizeSpeech({
  Text: script,
  VoiceId: 'Mark-Professional-NL',
  Engine: 'neural',
  OutputFormat: 'mp3'
});

// 4. Upload to S3
await s3.upload({
  Bucket: 'radio-news',
  Key: `news-${timestamp}.mp3`,
  Body: audio
});

// 5. Queue in Liquidsoap
await queueTrack({
  type: 'news',
  fileUrl: `news-${timestamp}.mp3`,
  duration: 120
});
```
