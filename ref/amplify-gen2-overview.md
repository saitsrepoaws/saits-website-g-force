## Notes
- Code-first DX: define backend in TypeScript; Amplify generates infra via CDK.
- Per-developer sandboxes; easy `sandbox` → ephemeral backend; `deploy` → shared envs.
- Works with any AWS service supported by CDK through custom resources.
